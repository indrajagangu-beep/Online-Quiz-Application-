# O🎯 Online Quiz Application in Java

A simple Java-based console application that allows users to take a multiple-choice quiz, calculates scores automatically, and displays the final result.

📌 Features

- Multiple-choice questions
- Instant score calculation
- Percentage calculation
- Grade generation
- Simple console-based interface
- Easy to customize and extend

🛠 Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Arrays
- Scanner Class

📂 Project Structure

OnlineQuizApplication/
│
├── QuizQuestion.java
├── OnlineQuiz.java
├── README.md
└── screenshots/

🚀 How to Run

Step 1: Clone the Repository

git clone https://github.com/your-username/OnlineQuizApplication.git

Step 2: Navigate to Project Folder

cd OnlineQuizApplication

Step 3: Compile the Program

javac QuizQuestion.java OnlineQuiz.java

Step 4: Run the Program

java OnlineQuiz
